# HackAFriend – Static Demo

**HackAFriend** is a platform designed to help hackathon enthusiasts connect with potential teammates who have complementary skills and shared interests. This static demo gives an overview of the user interface, user flow, and key features planned for the full version of the platform.

## 🔗 Live Demo

[https://hackafriend-14e.pages.dev/](https://hackafriend-14e.pages.dev/)

## 💡 Overview

HackAFriend solves the common problem faced by solo hackers or incomplete teams—finding the right teammates. It matches users based on skill sets, project interests, and availability, ensuring productive and collaborative hackathon experiences.

> This repository/demo is a frontend-only **static** prototype and does not include backend logic or real-time matching functionality.

## 🚀 Features (in demo)

- 🔐 Authentication (signup, login, OTP verification, forgot password)
- 👤 Onboarding flow: Username setup → Profile details
- 🧠 Skill & interest selection UI
- 🔍 Explore potential teammates (UI only)
- 💬 Chat UI preview (non-functional)

## 🧪 Demo Limitations

- No real-time backend (e.g., no actual matchmaking or messaging)
- Backend logic, user database, and real chat system will be added in the full release

- 🧑‍🤝‍🧑 Team management and project collaboration tools
